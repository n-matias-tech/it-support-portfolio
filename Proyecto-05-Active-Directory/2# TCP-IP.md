# Fase 2 - Configuración Inicial de Red y Conectividad

## Objetivo

Preparar el entorno de laboratorio para futuras implementaciones de Active Directory mediante la configuración de red básica y la validación de la comunicación entre equipos.

## Tecnologías utilizadas

* Windows Server 2012 R2
* Windows 10
* TCP/IPv4
* Hyper-V

## Descripción

En esta etapa se realizó la configuración inicial de los equipos para permitir la comunicación dentro del laboratorio y facilitar las futuras tareas de administración del dominio.

## Actividades realizadas

### Configuración TCP/IPv4

* Asignación de direcciones IP estáticas.
* Configuración de máscara de subred.
* Configuración de puerta de enlace.
* Configuración de DNS.

### Identificación de equipos

* Modificación de nombres NetBIOS para facilitar la administración del entorno.

### Administración remota

* Habilitación de acceso remoto en el servidor.

### Pruebas de conectividad

* Habilitación de tráfico ICMP en el Firewall de Windows.
* Validación de comunicación mediante comandos Ping.
* Verificación de conectividad entre servidor y cliente.
