# Fase 5 - Usuarios Estándar y Control de Privilegios

## Objetivo

Demostrar la administración de permisos dentro del dominio mediante la creación de un usuario estándar y la validación de las restricciones asociadas a su nivel de privilegios.

## Tecnologías utilizadas

* Windows Server 2012 R2
* Active Directory Domain Services (AD DS)
* Windows 10
* Hyper-V

## Descripción

En esta etapa se creó una cuenta de usuario estándar dentro del dominio para demostrar el funcionamiento de la autenticación centralizada y el control de privilegios proporcionado por Active Directory.

## Actividades realizadas

### Creación de usuario

* Creación de una cuenta de usuario estándar.
* Configuración de credenciales iniciales.
* Verificación de la cuenta dentro del dominio.

### Validación de acceso

* Inicio de sesión con la nueva cuenta.
* Verificación del acceso al dominio.
* Confirmación de autenticación mediante Active Directory.

### Control de privilegios

* Ejecución de tareas que requieren permisos elevados.
* Solicitud de credenciales administrativas.
* Validación de restricciones asociadas a usuarios estándar.

Se validó correctamente el funcionamiento de la autenticación de dominio y la aplicación de permisos según el nivel de privilegios asignado a cada usuario.
