# Fase 3 - Instalación de Active Directory y Creación del Dominio

## Objetivo

Implementar los Servicios de Dominio de Active Directory (AD DS) para comenzar la administración centralizada de usuarios, equipos y recursos dentro del laboratorio.

## Tecnologías utilizadas

* Windows Server 2012 R2
* Active Directory Domain Services (AD DS)
* DNS Server
* Hyper-V

## Descripción

En esta etapa se realizó la instalación de los Servicios de Dominio de Active Directory, la configuración del servicio DNS y la promoción del servidor a Controlador de Dominio mediante la creación de un nuevo bosque y dominio.

## Actividades realizadas

### Instalación de roles y características

* Apertura del Asistente para Agregar Roles y Características.
* Instalación del rol Active Directory Domain Services (AD DS).
* Instalación del servicio DNS Server.

### Configuración de Active Directory

* Promoción del servidor a Controlador de Dominio.
* Creación de un nuevo bosque.
* Creación de un nuevo dominio.
* Configuración inicial de los servicios de directorio.
