# Proyecto 05 - Active Directory Home Lab

## Objetivo

Preparar el entorno de laboratorio necesario para las prácticas de Active Directory mediante la creación de un servidor Windows Server y una máquina cliente Windows.

## Tecnologías utilizadas

* Hyper-V
* Windows Server 2012 R2
* Windows 10

## Descripción

En esta primera etapa se realizó la instalación y preparación de las máquinas virtuales que serán utilizadas durante el laboratorio.

### Máquina virtual - Servidor

**Nombre:** DC01

**Sistema Operativo:** Windows Server 2012 R2

**Función prevista:**

* Controlador de Dominio
* Servidor DNS
* Administración de Active Directory

### Máquina virtual - Cliente

**Nombre:** WIN10

**Sistema Operativo:** Windows 10

**Función prevista:**

* Equipo cliente para pruebas de dominio
* Validación de usuarios y políticas

## Actividades realizadas

* Creación de la máquina virtual del servidor.
* Instalación de Windows Server 2012 R2.
* Creación de la máquina virtual cliente.
* Instalación de Windows 10.
* Verificación del funcionamiento inicial de ambas máquinas virtuales.
